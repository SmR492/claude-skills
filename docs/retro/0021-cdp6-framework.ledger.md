## Acceptance (derived from the goal; the owner's words decide)

- G1 Every lifecycle phase (idea, exploration, concept, refinement, implementation, tests, retro, loop back) has an entry condition, an exit condition, its artefacts, its roles or skills and a gate, and runs on its own (single-agent) or orchestrated (multi-agent).
- G1b Three operating modes with equal standing: single agent, orchestrator-mediated multi-agent, agent team; each enforces the same contract, counters, captures and phase gates.
- G2 Autonomy is scalable: per assignment the human sets how far the cycle runs without a human gate; irreversible steps stay human.
- G3 No drift and no missed instruction: every normative rule carries an enforcement status (machine-checked by a named checker, or judgment with its counter-role), and the release check shows each checker firing.
- G4 Every open point below is closed with a solution all relevant counter-roles passed, or the human decided it.
