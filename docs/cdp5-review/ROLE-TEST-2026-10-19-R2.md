# Blind test round 2 (2026-10-19)

Method as in round 1: each role ran as a fresh subagent with its agent file as role text, the worker contract core v2 as injected context, and a realistic brief; the subagents were not told they were tested. Every brief carried at least one trap the role text says how to handle. Hooks were not installed, so the acknowledgement check, the shell guard and the usage log were simulated by the brief; the subagents ran on the session model, not on the model their frontmatter names. Target state for all runs: commit fb8ac28 (doctrine v6.0).
