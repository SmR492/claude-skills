# Blind test of the rebuilt agents and skills (2026-10-19)

Method: five agent definitions and one skill were given to fresh general-purpose subagents as their system prompt, together with the worker-contract core exactly as the SubagentStart hook injects it, and a realistic brief. The subagents were not told that they were being tested. The orchestrator session (this one) evaluated each report against the worker contract and the agent's own rights and duties. Limits: the subagents inherited the session model, not the `model` set in the agent files; the hooks (injection, acknowledgement check, Bash guard, usage log) were simulated by the prompt, not executed, because the plugins were not installed in this session. The install test in a fresh session remains open.

## Acknowledgement line format

Four of five agents wrote `contract: v1 89f435fc18eb`; one wrote `contract: v1 sha256:89f435fc18eb`. The check in `lib/contract.mjs` now accepts both forms, and rule 1 of the contract shows the exact line.

## Fixes applied after the test

- Bash guard rebuilt as an allowlist with a quote-aware segment parser, git global-option parsing, tool-script path rule, wrapper recursion (`wsl`, `bash -c`, `docker exec`), PowerShell cmdlet denylist, matcher `^(Bash|PowerShell)$`, exit 2 on unparseable input; the auditor's 87 counter-examples and the false positives are the test fixtures (`hooks/guard-bash.test.mjs`). Not enforced and recorded as such: the worker write boundary inside the worktree, arbitrary scripts under `plugins/` or `vendor/bin/`. The claim in DECISIONS.md A5/B rows, README and plugin.json now reads "tripwire"; the disposable environment the brief names is the boundary.
- Acknowledgement check accepts both `contract: v1 <hash>` and `contract: v1 sha256:<hash>`; rule 1 of the contract shows the exact line; `core.md` regenerated.
- `konzept-lint`: vague-word list extended (typisch, typically, roughly, approximately, about, usually), failed `struktur` checks itemised, dead `existsSync` fallback removed. Policy text: completeness of G3/G7/G8 is reported by konzept-reviewer in gaps, the dimensions stay presence counts.
- `build-packs.mjs`: redaction case-insensitive, tested with case variants.
- `frameworks.md`: prioritisation row names the missing backlog-scoring template (RICE, MoSCoW, WSJF).
- impl-refactor: Inputs require verbatim excerpts for §1.11/§32.13/§35.1 (absent from the copy); §27.1 Deletion-Test per extracted class on the split path; the decision row records the devil's-advocate result and the open scope question.
- Doctrine copy: header 5.1 with provenance line, redirect rows for Orbit-only paragraphs, §32.11 notes the §27.1 proxy.
- Model tiers set per agent file and pinned by `agents.test.mjs`.
- `git stash` is denied for workers (only `stash list`/`stash show` pass).

Decided after the report (D-13 batch 4): the tracked repository including the doctrine copy is English; impl-refactor is limited to merge and split; judgment agents run only inside a disposable environment the orchestrator has registered as a run grant (`scripts/grant-run.mjs`), which resolves the auditor's finding that "disposable environment" was a rule only the agent interpreted.

Open: duplicate retro numbers 0001/0002 in `docs/retro/`; domain-agents depends on cdp5-agents only in prose; the live hook test with installed plugins.
