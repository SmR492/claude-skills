A Venn diagram is a graphical representation that uses circles to illustrate the relationships between different sets of elements or concepts. It was developed by mathematician John Venn in the late 19th century and is used across mathematics, logic, statistics, data visualization, and problem-solving. Each circle represents a set and overlapping regions represent elements belonging to multiple sets, depicting intersections and differences.

- Disjoint sets: no overlapping region means the sets have no elements in common
- Intersection: overlapping region represents elements common to those sets
- Subset and Superset: one set entirely contained within another; larger is superset, smaller is subset
- Can be extended beyond three sets by adding more circles and showing their intersections
