# Hierarchical Task Analysis (HTA)

Hierarchical Task Analysis (HTA) is a method used to break down complex tasks into a hierarchical structure of subtasks, actions, and operations. It provides a systematic way of representing the relationships between different levels of tasks, allowing a detailed understanding of the task's structure, goals, and dependencies. HTA can help with process evaluations, schedule planning, risk identification, training needs, and workflow optimizations.

- Task Identification: select a task, define its boundaries and overall goal
- Decomposition: break the top-level task into meaningful subtasks, actions, and operations
- Task Relationships: identify dependencies, conditional relationships, ordering, or constraints
- Documentation: use diagrams, flowcharts, or outlines to represent the hierarchy
- Evaluation: review with SMEs/performers, identify missing/redundant steps, and revise
