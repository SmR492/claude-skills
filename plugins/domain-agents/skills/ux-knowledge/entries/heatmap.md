In UI/UX design, a heatmap is a visual representation of data that illustrates the areas of a user interface where users focus their attention or interact the most. It provides insights into user behavior, helping designers understand which elements are engaging, effective, or problematic. Heatmaps can track interactions such as clicks, taps, and cursor movement, and with advanced setups can track biometrics such as eye movement.

- Collection: gather user interaction data (mouse movements, clicks, scrolls, touch gestures) during testing, research, or real sessions
- Visualization: process data into a heatmap using a color spectrum from cool (blue) to warm (red); hotspots appear as warmer colors
- Analysis and Insights: identify patterns, engagement levels, usability issues; inform content placement, CTAs, visual hierarchy
