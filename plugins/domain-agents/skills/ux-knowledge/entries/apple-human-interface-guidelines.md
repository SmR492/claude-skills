# Apple Human Interface Guidelines (HIG)

The Apple Human Interface Guidelines (HIG) are a set of design principles and recommendations provided by Apple Inc. to assist developers in creating user-friendly and visually appealing software applications for Apple platforms. The HIG covers various aspects of user interface design, including visual design, interaction design, and user experience guidelines.

- Design Themes: embrace platform-specific themes (clarity in iOS, elegance in macOS)
- Layout and Structure: hierarchy, consistency, spacing, and alignment
- Navigation and Controls: tab bars, sidebars, menus, buttons, switches, sliders
- Typography and Text: legible fonts/sizes/styles, localization, Dynamic Type
- Graphics and Animation: well-crafted icons, illustrations, and animations
- Accessibility: VoiceOver, Dynamic Type, Assistive Touch
- App Store Guidelines: app icon design, previews, and privacy considerations
