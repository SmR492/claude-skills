A wizard user interface is a step-by-step interactive process that guides users through a series of tasks or decisions, simplifying complex processes and making them more manageable. Wizards are commonly used in user registrations, onboarding processes, form submissions, configuration setups, and complex task workflows.

- Task Chunking: break complex tasks into smaller, manageable chunks to reduce cognitive load
- Step-by-Step Progression: sequence of screens, each a specific task or decision point
- Clear Instructions and Guidance: help users understand what to do at each step
- Validation: real-time feedback, input validation, error messages, confirmations
- Flow: structured progression with ability to navigate back and forth
- Progress Indicators: progress bars or step counters show progress and remaining steps
- Flexibility: skip irrelevant steps or customize the experience
