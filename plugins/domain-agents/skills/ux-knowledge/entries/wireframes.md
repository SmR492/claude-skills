Wireframes are a visual design representation used in the early stages of product development, particularly software design. They are a low-fidelity blueprint of a user interface that represents the basic layout and structure of a web page, application, or other digital product. They help teams conceptualize and plan layout and flow, communicate to stakeholders, and explore options before committing to a design.

- Low-fidelity blueprint of a UI showing basic layout and structure
- Created using simple lines and shapes, from pen and paper to specialized software
- Help determine optimal placement of content and functionality
- Used to test user flow, navigation, and interactions and identify issues
- Often created alongside user personas, user journeys, and visual design concepts
