# Cognitive Task Analysis (CTA)

Cognitive Task Analysis (CTA) is a research methodology used to understand the cognitive processes and mental strategies that individuals employ while performing a task. CTA aims to uncover the knowledge, decision-making, problem-solving, and other cognitive activities involved in completing a task. The goal is to bridge the gap between observable behaviors and underlying cognitive processes.

- Interviews: open-ended questions about thought processes and decision-making strategies
- Think-Aloud Protocol: participants verbalize thoughts and actions while performing the task
- Cognitive Work Analysis (CWA): examine cognitive processes, social/organizational context, and task
- Knowledge Elicitation Techniques: knowledge maps, concept mapping, decision trees
- Cognitive Task Interviews: probe thought processes with specific task scenarios
- Cognitive Workload Assessment: subjective ratings, physiological, and performance measures
