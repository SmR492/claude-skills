# Screen reader testing

Screen reader testing evaluates the accessibility and usability of a digital interface for individuals who rely on screen readers to access content. It assesses how well a website, application, or product can be perceived, navigated, and interacted with using a screen reader.

- Screen Reader Selection: e.g. JAWS, NVDA, VoiceOver, aligned with target audience and platform
- Interaction: ensure headings, links, buttons, form controls, error messages, landmarks are recognized and announced; support keyboard/voice commands
- Alternative Content: assess accessibility of multimedia (videos, audio players, interactive components)
- Usability: evaluate overall UX for screen reader users and note issues
- Assistive Technology Compatibility: also test screen magnifiers, speech recognition, alternative input devices
