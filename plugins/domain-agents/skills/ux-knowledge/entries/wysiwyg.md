# WYSIWYG

Ref: `UX:wysiwyg` · Category: term · Entry version: 1
Source: ui-ux-design-guide Seite 74. Provenance: bulk extraction 2026-07-02, migrated to Orbit 2026-09-02 (riedl/nsai/doktrin/UX-wysiwyg.json); content unverified against a primary source. Treat figures and legal statements as unverified until checked.

WYSIWYG stands for 'What You See Is What You Get.' It refers to an interface or editor that allows users to see the final output of their work exactly as it will appear to the end-user. In web design or document editing, a WYSIWYG editor provides a visual representation of content, allowing formatting, media insertion, tables, and visual styling while showing the immediate visual impact.

- Commonly used in web CMS, word processors, website builders, and email marketing platforms
- Benefits: visual editing, ease of use, no coding required, efficiency, usability by non-technical users
- Limitations: generated code can be bloated or inconsistent; visual representation may not reflect all devices/platforms
