An accordion user interface is a graphical control that allows users to expand or collapse sections of content within a limited amount of screen space, helping organize and manage large amounts of information in a compact, navigable manner.

- Space Efficiency: conserves screen space by expanding/collapsing sections
- Content Organization: structured, hierarchical grouping of related information
- User Control: users choose which sections to expand, enhancing engagement
- Progressive Disclosure: reveals information gradually as users show interest
- Visual Clarity: collapsed sections show only headings, reducing clutter
