# Web Content Accessibility Guidelines (WCAG)

The Web Content Accessibility Guidelines (WCAG) are a set of guidelines for making web content more accessible to people with disabilities. They aim to ensure web content is perceivable, operable, understandable, and robust. Success criteria are organized into three levels of conformance: A (low), AA (medium), and AAA (high).

- Perceivable: present information and UI components so users can perceive them; provide alternatives for non-text content and ensure text is readable and distinguishable
- Operable: ensure UI components and navigation are operable via various input methods (keyboard, mouse, touch), with enough time to read and use content
- Understandable: make content clear and easy to read, use plain language, provide instructions/feedback, and help users avoid and correct mistakes
- Robust: make content reliably interpretable by a wide range of user agents by using standard HTML/CSS correctly and ensuring cross-browser/device compatibility
- Three conformance levels: A (low), AA (medium), AAA (high)
