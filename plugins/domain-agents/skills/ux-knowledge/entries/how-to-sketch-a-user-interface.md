# How to sketch a user interface

Sketching a user interface is an effective way to quickly explore and visualize design ideas. The excerpt outlines steps from gathering requirements through to transitioning into digital design tools.

- Gather Requirements: understand purpose, goals, functionality, target audience, key elements, and constraints
- Start Rough: sketch overall layout and structure with simple shapes and lines; capture basic arrangement and flow
- Consider Attention: balanced layout with clear grouping and spacing; create user flows/scenarios for an intuitive experience
- Get Feedback: share sketches with colleagues, stakeholders, or potential users to gather insights
- Iterate: refine and add detail, experiment with variations; don't worry about making it perfect
- Use Annotations: add notes to explain elements or interactions
- Transition: move to digital design tools for refined wireframes or prototypes
