# Use cases and user stories

Use cases and user stories are two techniques used in software development to capture requirements from the user's perspective, but they have key differences. Use cases are more detailed and comprehensive, describing specific interactions between user and system (often as diagrams/flowcharts), while user stories are shorter and focused on the user's needs and desired outcomes. Use cases are often used in traditional Waterfall processes, whereas user stories are more common in Agile.

- Use case: detailed description of how a user/system interacts to accomplish a goal, shown as diagrams or flowcharts
- User story: short statement in the format 'As a [type of user], I want [feature], so that [benefit]'
- Difference in level of detail: use cases more detailed, user stories more focused on needs/outcomes
- Difference in process: use cases with Waterfall (up-front requirements), user stories with Agile (iterative, incremental)
