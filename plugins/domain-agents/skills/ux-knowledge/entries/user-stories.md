# User stories

A user story is a technique used in software development to capture a description of a feature from the user's perspective. It is a short, simple statement describing a user's need or requirement, often used in Agile development as a basis for planning and prioritizing work. It typically follows a three-part format: a persona/user, a need/requirement, and a goal/outcome.

- Three parts: a persona or user, a need or requirement, and a goal or outcome
- Example: 'As a customer, I want to view my order history so that I can track my purchases and returns.'
- Simple and easy to understand for technical and non-technical stakeholders
- Serve as a reminder of the user's perspective throughout development
- Organized and prioritized using a product backlog, most valuable stories first
