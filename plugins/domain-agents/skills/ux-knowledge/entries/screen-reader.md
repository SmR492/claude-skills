A screen reader is an assistive technology software designed to help individuals with visual impairments or blindness access and interact with digital content. It is a crucial tool for ensuring inclusive user experiences in UI/UX design.

- Accessibility: provides an audio representation of visual content, reading aloud text, icons, buttons, and other elements
- Accessibility Guidelines: use proper semantic HTML markup, provide alternative text for images, ensure keyboard accessibility
- Interaction: offers navigation via headings, links, buttons, and form controls through spoken commands or keyboard input
- Content and Context: conveys structure and hierarchy of headings/lists, plus context cues (images, form requirements, error messages)
- Screen Reader Compatibility Testing: reveals how a design is perceived audibly and identifies missing or mislabeled elements
