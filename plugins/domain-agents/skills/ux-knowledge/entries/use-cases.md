# Use cases

A use case is a technique used in software engineering to describe and define the interactions between a user or system and a product. It captures the functional requirements of a system and is an important part of requirements gathering, outlining the steps taken to achieve a specific goal and identifying inputs, outputs, and actors. Use cases help ensure the product meets its intended audience's needs and provide a way to test and validate functionality and usability.

- Captures functional requirements and defines a specific user/system interaction
- Identifies inputs, outputs, and actors involved
- Typically presented as a diagram or table, may include descriptions and flow charts
- Functional use cases: behavior under normal conditions
- Alternate use cases: behavior under different or unexpected conditions
- Exception use cases: how the system handles errors or unexpected input
