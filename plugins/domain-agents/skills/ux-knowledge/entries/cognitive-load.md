# Cognitive load

Cognitive load, in product design and usability, refers to the amount of mental effort or processing capacity users must expend to interact with a product, understand its interface, and accomplish tasks. It is a crucial concept in UX design, as minimizing unnecessary cognitive load can significantly improve usability and user satisfaction. There are three main types.

- Intrinsic Cognitive Load: load from the inherent complexity of a task; cannot be eliminated but can be made manageable
- Extraneous Cognitive Load: unnecessary load from poor design and presentation; a key goal to reduce
- Germane Cognitive Load: beneficial load necessary for learning and problem-solving; made as efficient as possible
