# Data schema

A data schema is the structure or blueprint of a database. It defines the organization, storage, and relationships among data elements, tables, views, and other database objects, providing a framework for organizing data and ensuring data integrity and consistency. It typically describes each data element (data type, size, format) and defines relationships via primary and foreign keys. Schemas are usually created with a data definition language (DDL) such as SQL, stored in the database catalog, and can be modified as requirements change.

- Entity-Relationship (ER) schema: defines entities/objects, their attributes, and relationships
- Relational schema: defines tables, columns, and relationships in a relational database
- Object-oriented schema: defines objects, classes, and inheritance relationships in an object-oriented database
- Document schema: defines the structure and relationships of documents in a document-oriented database
