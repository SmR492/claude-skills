A ribbon user interface is a graphical control that presents a set of commands or actions in a horizontal bar across the top of an application or document. It is often used in productivity software to provide a visually organized and easily accessible set of tools and options.

- Grouping: organize commands into logical, visually distinct groups (formatting, editing, document functions)
- Discoverability: present a wide range of commands in a visible, accessible manner
- Visual Hierarchy and Priority: prominent placement or larger icons for frequently used/primary commands
- Contextual Tool Sets: adapt displayed commands based on the context of the user's actions
- Customizability: users can add/remove commands, rearrange groups, or create custom tabs
