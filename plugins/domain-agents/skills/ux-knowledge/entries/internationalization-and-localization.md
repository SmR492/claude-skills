# Internationalization and localization (i18n / l10n)

Ref: `UX:internationalization-and-localization` · Category: method · Entry version: 1
Source: ui-ux-design-guide Seite 133-134. Provenance: bulk extraction 2026-07-02, migrated to Orbit 2026-09-02 (riedl/nsai/doktrin/UX-internationalization-and-localization.json); content unverified against a primary source. Treat figures and legal statements as unverified until checked.

Internationalization and localization are steps in creating software or a website usable by people in different regions, cultures, and languages. Internationalization (i18n) is designing software so it can be easily localized later without significant changes to the underlying code. Localization (l10n) is translating and adapting the software for use in a particular region. In short, internationalization makes software ready for localization, while localization adapts it to work well in a particular region.

- Internationalization process: separate all UI text from code, handle dates/times/regional settings, support wide range of character sets and language features
- Internationalization goal: make future localized versions easy without major code changes
- Localization: translate UI text, adapt to local date/time formats, currencies, region-specific settings
- Internationalization steps: Plan and Analyze; Design and Develop
- Localization steps: Translate; Adapt; Format
- Shared steps: Test (in each target market); Maintain
