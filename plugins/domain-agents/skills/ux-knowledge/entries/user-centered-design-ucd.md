# User-centered design (UCD)

User-centered design (UCD) is an approach to designing products, systems, or interfaces that places the needs, goals, and preferences of the end users at the forefront of the design process. It involves understanding users through research and iterative testing, and using that knowledge to guide design decisions. Benefits include improved user satisfaction, enhanced usability, reduced development costs, and ultimately a competitive advantage.

- User Involvement: user research, interviews, surveys, and usability testing; consider physical environment, user characteristics, technological constraints, social/cultural influences
- User Goals: understand goals and context of use so the design supports users' objectives correctly and efficiently
- Design for Usability: build prototypes/mock-ups, run usability testing, gather and incorporate feedback for intuitive, easy-to-learn, error-resistant designs
- Multidisciplinary Collaboration: designers, developers, researchers, and other stakeholders balancing user needs, technical feasibility, and business goals
