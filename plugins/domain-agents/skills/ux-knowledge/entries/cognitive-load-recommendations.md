# Cognitive load - recommendations

Source: ui-ux-design-guide Seite 77. Provenance: bulk extraction 2026-07-02, migrated to Orbit 2026-09-02 (riedl/nsai/doktrin/UX-cognitive-load-recommendations.json); content unverified against a primary source. Treat figures and legal statements as unverified until checked.

Reducing cognitive load in product design makes the user experience more efficient and enjoyable and increases the likelihood of users completing tasks and returning. It is fundamental to creating user-friendly, intuitive interfaces. The text provides a set of recommendations for reducing cognitive load.

- Simplify and Streamline: minimize complexity, remove unnecessary steps and information
- Use Clear and Consistent Design: consistent UI, familiar design patterns and terminology
- Plan Effective Information Hierarchy: organize logically, use headings, lists, and color as visual cues
- Provide Feedback and Guidance: clear feedback on actions/errors, tooltips when necessary
- Leverage Progressive Disclosure: present information gradually, only when needed
- Prioritize Content: focus on important content, de-emphasize less important elements
- Test Usability: conduct usability testing with real users
