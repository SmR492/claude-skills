# Design canvas

A design canvas in UI/UX design is a visual framework or template that helps designers organize and structure their thoughts, ideas, and design concepts. It captures and communicates key aspects of a design project, providing a holistic view of the product or experience being designed.

- Problem Statement: define the problem or challenge the design aims to solve
- Personas: describe target users, their characteristics, needs, motivations, and goals
- Journeys: map the user's journey and touchpoints when interacting with the product
- Information Architecture: plan content hierarchy, navigation, and layout
- Visual Design: sketch layout, components, and visual elements (low- and/or high-fidelity)
- Interaction Design: define user flows, navigation patterns, and interactive elements
- Testing: outline methods such as usability testing, focus groups, and behavioral analytics
