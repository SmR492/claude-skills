A state diagram (also state machine diagram or state chart diagram) is a type of behavioral diagram in software engineering that describes the behavior of an object or system over time. It is a graphical representation of the states, events, and transitions that occur in the system.

- States: a condition in which an object exists, shown as named rectangles (e.g. traffic light Red/Yellow/Green)
- Transitions: a change from one state to another, shown as labeled arrows
- Events: something that occurs to trigger a transition, shown as labels on arrows
- Actions: something that occurs during a transition, shown as labels on arrows
- Guards: a condition that must be true for a transition, shown as Boolean expressions in square brackets
