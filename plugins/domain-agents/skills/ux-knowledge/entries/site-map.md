A site map is a visual representation of the hierarchical structure and organization of a website's content, essentially a list of all pages and sections organized to help users navigate and understand the site. Site maps can be presented as hierarchical diagrams, flowcharts, or lists, and can also be interactive.

- Typical elements: Sections (Products, Support, Contact, FAQ), Links, Page hierarchy
- Help users navigate the site with a clear, organized overview
- Improve search engine optimization by giving engines an overview of structure/content
- Streamline website design by helping designers plan and organize content and structure
