# Usability

Usability refers to the ease of use and effectiveness of a product, system, or interface in achieving its intended purpose. It plays a crucial role in user experience (UX) design because it directly impacts how users perceive and interact with a product. Benefits can include enhanced user experience, increased productivity, reduced support costs, reduced errors, and competitive advantages.

- Learnability: users can quickly understand and learn to use a system
- Efficiency: users accomplish tasks with minimal steps, clicks, or actions
- Memorability: users remember how to use a product even after inactivity
- Error Prevention: users can discover and correct mistakes; clear error messages and easy undo/recovery
- User Satisfaction: users feel satisfied, confident, and positive about the experience
