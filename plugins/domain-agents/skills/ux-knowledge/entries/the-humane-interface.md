# The Humane Interface (Jef Raskin)

Das Buch 'The Humane Interface: New Directions for Designing Interactive Systems' des HCI-Experten Jef Raskin beschreibt seine Vision fuer intuitivere, effizientere und nutzerfreundlichere Benutzeroberflaechen.

- User-Centered Design: Beduerfnisse, Ziele und mentale Modelle der Nutzer priorisieren
- Direct Manipulation: natuerliche, intuitive Interaktion mit Objekten und Aktionen
- Modeless Interfaces: modusfreie Interfaces, da Modus-Wechsel Verwirrung/Fehler verursachen
- Simplification: komplexe Aufgaben vereinfachen, unnoetige Schritte reduzieren, automatisieren
- Information Retrieval: nuetzliche Suchalgorithmen, Browsing-Interfaces, Informationshierarchien
- Error Prevention and Recovery: Fehler minimieren, klares Feedback, intuitive Recovery
